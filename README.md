# Лабораторная работа № 1. Абстрактные структуры данных

Индивидуальный вариант № 4 — **Full Binary Tree**.

## Состав проекта

- **C++17:** динамический массив, односвязный список, двусвязный список, стек, очередь и бинарное дерево поиска.
- **Дерево:** вставка узлов, поиск, проверка свойства Full Binary Tree и четыре обхода.
- **Хранение данных:** JSON-файл.
- **Go:** дополнительная реализация массива, односвязного и двусвязного списков, стека и очереди. Дерево реализовано на C++.

## Структура каталогов и файлов

```text
include/       заголовочные файлы
src/           исходные файлы C++
go/            исходные файлы Go
.vscode/       настройки и задачи Visual Studio Code
main.cpp       точка входа C++-программы
Makefile       правила сборки C++-проекта
data.json      файл данных
run_demo.sh    демонстрационный запуск для Linux
run_demo.bat   демонстрационный запуск для Windows
```

## Требования

### Windows

Для сборки в Windows используется MSYS2 с окружением **UCRT64**. Необходимые пакеты устанавливаются командой:

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-json-c mingw-w64-ucrt-x86_64-pkgconf make
```

Для работы с проектом также требуется Visual Studio Code и расширение C/C++ от Microsoft.

В терминале MSYS2 UCRT64 команда `g++` должна быть доступна через PATH. Запуск Visual Studio Code из этого терминала выполняется командой:

```bash
code .
```

### Ubuntu / Debian / WSL

Необходимые зависимости устанавливаются командами:

```bash
sudo apt update
sudo apt install g++ make pkg-config libjson-c-dev
```

## Сборка

Сборка C++-проекта выполняется из корневого каталога:

```bash
make
```

После успешной сборки создаётся исполняемый файл `dbms` (в Windows — `dbms.exe`).

Для очистки каталога от исполняемых файлов используется команда:

```bash
make clean
```

## Запуск в Visual Studio Code

В каталоге `.vscode/` настроены задачи сборки и демонстрационного запуска.

- **Build C++ project** — сборка проекта командой `make`.
- **Run tree demo** — сборка и запуск демонстрационного сценария для бинарного дерева.

Сборка также доступна через команду **Terminal → Run Build Task** или сочетание клавиш `Ctrl+Shift+B`.

Демонстрационный сценарий последовательно создаёт дерево, выполняет проверку Full Binary Tree, выводит обходы, выполняет поиск и добавляет повторяющееся значение. Для демонстрации используется отдельный файл `data_demo.json`; файл `data.json` не изменяется.

## Формат команд

Общий формат запуска:

```text
./dbms --file <файл> --query "<КОМАНДА> <ИМЯ_СТРУКТУРЫ> <АРГУМЕНТЫ>"
```

Пример добавления узлов:

```bash
./dbms --file data.json --query "TINSERT mytree 8"
./dbms --file data.json --query "TINSERT mytree 4"
./dbms --file data.json --query "TINSERT mytree 12"
```

Проверка свойства Full Binary Tree:

```bash
./dbms --file data.json --query "TFULL mytree"
```

Вывод обходов дерева:

```bash
./dbms --file data.json --query "TPRINT mytree"
```

В Windows имя исполняемого файла — `dbms.exe`.

### Команды бинарного дерева

| Команда | Назначение |
|---|---|
| `TINSERT` | Добавление ключа |
| `TFIND` | Поиск ключа |
| `TFULL` | Проверка свойства Full Binary Tree |
| `TPRINT` | Вывод обходов дерева |

В бинарном дереве поиска меньшие ключи размещаются в левом поддереве, большие и равные — в правом. Повторяющиеся значения допускаются.

## Дополнительная сборка Go

Go-версия включает динамический массив, односвязный и двусвязный списки, стек и очередь. Реализация дерева на Go отсутствует.

Сборка выполняется из каталога `go/`:

```bash
go build -o dbms_go .
```

Пример запуска:

```bash
./dbms_go --file ../data.json --query "SPUSH mystack item"
```

Сборка Go не входит в основную сборку C++ через Makefile.
